# Support

This document uses ASD-STE100 Simplified Technical English.

## Best Path By Topic

- For usage questions, operational questions, or maintainer contact, email `minecraft-ping@omkhar.net`.
- For a bug or regression, [open a bug report](https://github.com/omkhar/minecraft-ping/issues/new?template=bug_report.yml).
- For a feature request, [open a feature request](https://github.com/omkhar/minecraft-ping/issues/new?template=feature_request.yml).
- To select an issue form, [browse the issue templates](https://github.com/omkhar/minecraft-ping/issues/new/choose).
- For a security vulnerability, [open a private security advisory](https://github.com/omkhar/minecraft-ping/security/advisories/new) or follow [SECURITY.md](SECURITY.md).

## What To Include

When asking for help by email, include:

- the `minecraft-ping -V` output or the exact commit
- the command you ran
- the target edition and address family when relevant
- the observed output or error
- the operating system and architecture

## Expectations

The maintainer provides support on a best-effort basis.
Use public issues and pull requests for bugs and feature work.
This practice gives the repository an auditable history.
Keep security reports private until a fix and disclosure plan are ready.
